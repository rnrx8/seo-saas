# DIG Google検索画面取得

DIGで生成を押したときだけGoogle検索タブを開き、通常の自然検索カードから順位・タイトル・URLを読み取ります。広告・AI概要・Search Consoleの個人カードを取得対象にしません。取得結果は元のDIGタブに返され、記事と検索語に紐付けて保存されます。外部APIへのフォールバックはありません。

権限はGoogle（www.google.co.jp / www.google.com）の画面読み取りとDIG（本番 / localhost:3000）の連携のみ。閲覧履歴・Cookie・パスワード・他サイト全般への権限は要求しません。利用時はChromeとDIGのタブを開いておく必要があります。CAPTCHAや同意画面を自動処理せず、取得できなければ記事生成前に止まります。

## 導入
1. Chromeの拡張機能ページ `chrome://extensions` を開く。
2. デベロッパーモードを有効にし、「パッケージ化されていない拡張機能を読み込む」でこのフォルダを選ぶ。
3. DIGを再読み込みし、「検索結果の取得設定」で接続テストを実施。

ユーザーが導入を承認してからインストールしてください。削除は通常のChrome拡張機能画面から行えます。
