# DIG Google検索画面取得

DIGで生成を押したときだけGoogle検索タブをバックグラウンドで開き、通常の自然検索カードから順位・タイトル・URLを読み取ります。広告・AI概要・Search Consoleの個人カードを取得対象にしません。取得結果は元のDIGタブに返され、記事と検索語に紐付けて保存されます。外部APIへのフォールバックはありません。

権限はGoogle（www.google.co.jp / www.google.com）の画面読み取りとDIG（本番 / localhost:3000）の連携のみ。閲覧履歴・Cookie・パスワード・他サイト全般への権限は要求しません。利用時はChromeとDIGのタブを開いておく必要があります。CAPTCHAや同意画面を自動処理せず、取得できなければ記事生成前に止まります。

## 導入
1. Chromeの拡張機能ページ `chrome://extensions` を開く。
2. デベロッパーモードを有効にし、「パッケージ化されていない拡張機能を読み込む」でこのフォルダを選ぶ。
3. DIGを再読み込みし、「検索結果の取得設定」で接続テストを実施。

ユーザーが導入を承認してからインストールしてください。削除は通常のChrome拡張機能画面から行えます。

## 1.1.0への更新

既存の利用者はChromeの`chrome://extensions`で「DIG Google検索画面取得」を再読み込みし、DIGページも更新してください。正常取得時は検索タブを自動で閉じ、DIGから画面を切り替えません。CAPTCHAや同意が必要な場合だけ取得エラーを案内します。失敗した記事の再実行は検索を再取得せず、サーバーに保存済みの途中成果から再開します。
